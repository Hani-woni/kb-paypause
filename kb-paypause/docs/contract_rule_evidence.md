# 계약서 위험규칙 근거표

## 작성 원칙

- 공식문서와 한국소비자원 분쟁조정사례에서 확인되는 내용만 규칙으로 사용한다.
- 개별 사례의 판단을 모든 계약에 그대로 일반화하지 않는다.
- 법적 효력이 없다고 공식 자료에서 명확히 판단한 경우와 단순 확인이 필요한 경우를 구분한다.
- 계약서 원문에서 탐지된 문장은 최종 결과의 `evidence`에 그대로 포함한다.
- 자료에서 근거를 확인하지 못한 규칙은 구현하지 않고 보류한다.

---

## 1. NORMAL_PRICE_DEDUCTION

| 항목 | 내용 |
|---|---|
| 규칙명 | 정상가 기준 공제 |
| 위험코드 | `NORMAL_PRICE_DEDUCTION` |
| 상태 | 공식 근거 확인 완료 |
| 기본 위험도 | `high` |
| 탐지 대상 | 정상가, 정가, 할인 전 가격을 기준으로 이용대금 또는 환급액을 계산한다는 조항 |
| 공식 근거 | `case_normal_price_deduction_2025.pdf` |
| 보조 근거 | `case_contract_not_provided_2020.pdf` |
| 근거 요약 | 정상가를 기준으로 환급액을 계산하는 조항의 효력이 인정되지 않았고, 실제 총 계약대금을 기준으로 이용대금과 위약금을 계산함 |
| 서비스 출력 | 실제 지급액보다 불리한 환급 결과가 발생할 수 있는 조항 |
| 판단 한계 | 모든 할인 또는 정상가 표시 자체가 문제라고 판단하지 않음. 중도해지 환급 계산에 정상가를 적용하는 경우만 탐지 |

## 2. NON_REFUNDABLE

| 항목 | 내용 |
|---|---|
| 규칙명 | 할인상품 환불 불가 |
| 위험코드 | `NON_REFUNDABLE` |
| 상태 | 공식 근거 확인 완료 |
| 기본 위험도 | `high` |
| 탐지 대상 | 할인·이벤트·프로모션 상품이라는 이유로 중도해지와 환급을 전면 금지하는 조항 |
| 공식 근거 | `case_pt_gym_bundle_2025.pdf` |
| 근거 요약 | 할인된 가격으로 계약했다는 이유로 환급이 불가하다는 약관의 효력이 인정되지 않음 |
| 서비스 출력 | 할인상품이라는 이유만으로 환급을 전면 제한하는 조항 |
| 판단 한계 | 이미 제공된 이용분의 공제까지 금지된다는 의미는 아님 |

## 3. PENALTY_EXCESS

| 항목 | 내용 |
|---|---|
| 규칙명 | 위약금 상한 초과 |
| 위험코드 | `PENALTY_EXCESS` |
| 상태 | 공식 근거 확인 완료 |
| 기본 위험도 | `high` |
| 탐지 대상 | 소비자 사정으로 중도해지할 때 총 계약대금의 10%를 초과하는 위약금 |
| 공식 근거 | `continuous_transaction_refund_standard_2019-9.pdf` 제4조 |
| 사례 근거 | `case_contract_not_provided_2020.pdf`, `case_normal_price_deduction_2025.pdf` |
| 근거 요약 | 사업자 귀책사유 없이 해지되는 경우 위약금은 공식 기준의 상한을 초과할 수 없으며, 헬스장 사례에서는 총 계약대금의 10%를 적용함 |
| 서비스 출력 | 계약서상 위약금 비율이 공식 기준보다 높을 가능성이 있음 |
| 판단 한계 | 사업자 귀책이나 쌍방 귀책이 없는 경우에는 위약금이 부과되지 않을 수 있으므로 최종 귀책사유를 자동 확정하지 않음 |

## 4. BUSINESS_LIABILITY_EXEMPTION

| 항목 | 내용 |
|---|---|
| 규칙명 | 사업자 책임 전면 면제 |
| 위험코드 | `BUSINESS_LIABILITY_EXEMPTION` |
| 상태 | 공식 사례 근거 확인 완료 |
| 기본 위험도 | `high` |
| 탐지 대상 | 시설 사고와 사업자 관리상 과실까지 사업자가 일절 책임지지 않는다는 조항 |
| 공식 근거 | `case_business_liability_gym_2024.pdf` |
| 근거 요약 | 헬스장 사업자에게 시설을 안전하게 유지·관리할 책임이 있으며, 이용자 과실 가능성만으로 사업자가 전면 면책되지는 않음 |
| 서비스 출력 | 사업자의 시설 안전관리 책임까지 전면 면제할 수 있는 조항 |
| 판단 한계 | 불가항력이나 이용자의 고의·과실에 따른 책임 경감·면제 가능성까지 위험으로 판단하지 않음 |

## 5. CONTRACT_TERMS_NOT_PROVIDED

| 항목 | 내용 |
|---|---|
| 규칙명 | 계약서 또는 환급규정 미교부 |
| 위험코드 | `CONTRACT_TERMS_NOT_PROVIDED` |
| 상태 | 공식 사례 근거 확인 완료 |
| 기본 위험도 | `medium` |
| 탐지 대상 | 계약서 미교부, 환급규정 미제공, 구두 설명만 했다는 내용 |
| 공식 근거 | `case_contract_not_provided_2020.pdf` |
| 근거 요약 | 계약서를 교부하지 않았고 정상가 환급규정을 매장에 게시한 것만으로는 충분한 설명으로 보기 어렵다고 판단함 |
| 서비스 출력 | 계약조건과 환급규정을 서면으로 확인하기 어려운 상태 |
| 판단 한계 | OCR에 계약서 전체가 입력되지 않았다는 이유만으로 실제 미교부를 단정하지 않음 |

## 6. BUNDLE_PRICE_UNCLEAR

| 항목 | 내용 |
|---|---|
| 규칙명 | 결합상품 항목별 가격 불명확 |
| 위험코드 | `BUNDLE_PRICE_UNCLEAR` |
| 상태 | 서비스 확인규칙 |
| 기본 위험도 | `medium` |
| 탐지 대상 | PT와 헬스 이용권이 함께 판매됐지만 항목별 가격 또는 이용단위가 구분되지 않은 계약 |
| 참고 사례 | `case_pt_gym_bundle_2025.pdf` |
| 근거 요약 | 결합계약의 환급 과정에서 PT 이용대금과 헬스장 이용대금을 구분하여 계산함 |
| 서비스 출력 | 항목별 가격이 없어 실제 이용분과 잔여 환급액 계산이 어려움 |
| 판단 한계 | 항목별 가격 미기재 자체를 위법이라고 단정하지 않음 |

## 7. SESSION_DEDUCTION_CHECK

| 항목 | 내용 |
|---|---|
| 규칙명 | PT 횟수 차감 기준 확인 |
| 위험코드 | `SESSION_DEDUCTION_CHECK` |
| 상태 | 서비스 확인규칙 |
| 기본 위험도 | `medium` |
| 탐지 대상 | 실제 수업 제공 여부와 관계없이 횟수가 자동 차감되거나 유료 횟수와 서비스 횟수가 구분되지 않는 조항 |
| 참고 사례 | `case_pt_trainer_absence_2024.pdf` |
| 근거 요약 | 계약횟수, 실제 이용횟수, 서비스 횟수를 구분하여 잔여 횟수와 환급액을 판단함 |
| 서비스 출력 | 실제 제공 횟수와 계약상 차감 기준을 추가로 확인해야 함 |
| 판단 한계 | 노쇼·당일취소 차감이 항상 무효라고 단정하지 않음 |

## 8. CLOSURE_PROTECTION_MISSING

| 항목 | 내용 |
|---|---|
| 규칙명 | 폐업·휴업 시 보호조항 미확인 |
| 위험코드 | `CLOSURE_PROTECTION_MISSING` |
| 상태 | 근거 원문 추가 확인 후 구현 |
| 기본 위험도 | `medium` 예정 |
| 탐지 대상 | 폐업·휴업·영업중단 시 미사용 금액 처리 또는 계약 해지 방법이 확인되지 않는 계약 |
| 확인 예정 문서 | `gym_standard_terms_2025.hwpx` |
| 현재 판단 | 업로드된 파일의 해당 조항 원문을 정확히 확인한 뒤 규칙 확정 |
| 판단 한계 | 보호조항이 없다는 이유만으로 곧바로 위법이라고 단정하지 않음 |
